Your stair geometry will appear here.

For Part 3 exit stairs the Ontario Building Code keeps risers between 125 and 200 mm and tread runs at 250 mm or more, with at least 1,100 mm clear between handrails. This tool picks the riser count that keeps every riser in range and equal — uneven risers are both a Code problem and a tripping hazard — then totals the run. Stairs inside a single dwelling unit are designed to Part 9 instead.
